# Default exercise images

Photos in `images/` come from [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
by yuhonas, released into the public domain under [The Unlicense](https://unlicense.org/).
Folder names match the dataset's exercise ids.

`Seated_Wide-Grip_Row` combines two photos from the same dataset: `Seated_Cable_Rows/0.jpg`
and `Low_Pulley_Row_To_Neck/1.jpg` (there is no wide-bar seated row in the dataset).
