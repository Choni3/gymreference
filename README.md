# GymReference

A lightweight iPhone-friendly web app to keep **technique references for your gym
routine**: lots of photos (including frames grabbed from tutorial videos),
technique cues, notes and links for every exercise. It complements Strong, which
logs your sets but has short exercise descriptions.

See [docs/SCOPE.md](docs/SCOPE.md) for goals, non-goals and design choices.

## Features

- Routines with an ordered list of exercises and sets × reps
- Exercise cards: swipeable photo gallery with captions, cues, notes, video links
- Known lifts start from **default cues and 2 reference photos** (start / end
  position, captioned); add your own photos, video frames and dated notes right
  from the exercise page (🖼 Photos · 🎬 Video frame · 📝 Note)
- Add many photos at once, or **grab frames from a video** (scrub → capture)
- Step through a routine at the gym with Prev / Next
- Import routines from a **Strong CSV export**
- Works offline, data stays on your device; export/restore a backup file

## Use it on your iPhone

1. Open <https://choni3.github.io/gymreference/> in **Safari**.
2. Tap **Share → Add to Home Screen**. Opening it from the home screen keeps
   your data safe from Safari's storage clean-up and works offline.
3. Optional: in Strong, *Settings → Export Strong Data*, save the CSV to Files,
   then in GymReference *Settings → Import Strong CSV*.
4. Export a backup from Settings now and then (e.g. to iCloud Drive).

## Development

No build step: plain HTML, CSS and ES modules.

```sh
npm run serve   # python3 -m http.server 8080 → http://localhost:8080
npm test        # Strong CSV parser tests (Node 20+)
```

When you ship changes, bump `VERSION` in `sw.js` so installed copies refresh
their offline cache. Icons are generated by `python3 scripts/make_icons.py icons`.
Default exercises (researched cues + source links) live in `js/seed.js`; bump
`DEFAULTS_VERSION` there when changing them. Their photos are in `defaults/images`
(public domain, from [free-exercise-db](https://github.com/yuhonas/free-exercise-db)).
